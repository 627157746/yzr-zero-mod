# Wendy（KAERIMICHI / Wendy v1.01）替换成年魂 — 安装说明

## 当前状态
- 采用通用管线（`tools/extract_package.py` + `tools/blender/adapt_humanoid.py` + `tools/ue/setup_assets.py`）构建。
- 离线验证：5 段动作 20 个采样点手部误差全部为 `0.0 cm`（**尚未进游戏实测，状态：未验证**）。
- 源模型：`source/Wendy v1.01.unitypackage`（KAERIMICHI，VRChat Humanoid 模型，117233 顶点、394 骨，含 18 节尾巴链）。
- 配置：`mods/wendy/mod.json`（纯声明式配置，无专属钩子脚本）。

## 版本（只装一个，文件名相同，换版本直接覆盖）
| 文件夹 | 说明 |
|---|---|
| `default-phys`（推荐先试） | 长白发 / 大袖 / 裙摆 / 尾巴 / 蝴蝶结飘带含次级物理（`RigidBody`），带裙摆×双腿、尾巴×双腿防穿模碰撞 |
| `default-basic` | 同模型、同贴图，**完全无次级物理**；物理抖动或穿模时作对照 |

## 适用范围
- Steam 版《影之刃零》，build 26367565。游戏更新后可能失效。
- 只替换成年魂的默认服装；少年魂、其他服装、过场动画未逐一适配。
- 不需要 UE4SS，纯 `.pak/.ucas/.utoc` 静态封包，只改模型与贴图，不改游戏脚本或原版骨架 `Hun_Skin_Skeleton`。

## 安装
1. 退出游戏。
2. 打开游戏目录：Steam 右键《影之刃零》→ 管理 → 浏览本地文件（文件夹名 `PBZ`）。
3. 把版本文件夹里的 `~mods` 整个复制到 `PBZ\ProjectPBZ\Content\Paks\`，覆盖同名文件。装好后应有：
   `PBZ\ProjectPBZ\Content\Paks\~mods\zzz_Wendy_P.pak`、`.ucas`、`.utoc` 三个文件。
4. 若装过其他「替换魂」mod，请先把它们移出 `~mods`（所有替换魂的 mod 只能同时装一个）。
5. 启动游戏，读取成年魂存档。

## 卸载
退出游戏，删除 `PBZ\ProjectPBZ\Content\Paks\~mods\` 下的 `zzz_Wendy_P.pak`、`.ucas`、`.utoc` 三个文件即可。

## 本模型的配置取舍
- **服装形态**：保留大袖 `Clothes_arm_cover`，删除互换用的短袖 `Clothes_arm_cover_short`（`delete_meshes`）。
- **身高**：`scale: 1.37`，成品高度 186.85 cm（原始 135.97 cm × 1.37）。若要更矮，改 `model.scale` 后重跑 `build-mod.ps1`。
- **尾巴（卷曲 / 展开）**：`hooks/curl_tail.py` 把 `Tail_02..18` 逐段绕 X 轴转 **-14°**（累计约 -150°）烘进绑定姿势，成品静止时尾巴向后上方卷到背侧（尖端 z≈167 cm，离大腿 78.8 cm），不再拖地。运动时的「展开」由物理惯性实现：`tail` 组的 `swing` 放到 55°、`twist` 25°、`stiff` 降到 60、`damp` 14、`lin`/`ang` 提到 2.2/8.0 —— 绑定姿势是卷的，跑动甩动时刚体惯性把卷展开再回弹。
  - 走的是 mod 专属 hook 而非 `model.rest_rotations`，因为后者与 `keep_shape_keys`（眨眼）互斥会直接 fail。
- **裙摆防穿模**：`skirt` 组的 `swing` 从 25° 提到 **70°**、`twist` 8°→14°、`stiff` 200→**60**、`damp` 26→30、`lin` 2.0→3.5。原参数把裙摆硬拽回绑定姿势，腿一抬就从缺口穿出去；放软之后裙摆能被腿推开而不再反向穿模。`skirt×leg` 碰撞对保持全开（372 对 = 93 骨 × 4 腿骨）。
  - 注：`Costume1` 里 `Hips` 主导的 4738 顶点（z 96.7~117.1）与 `Chest/Spine` 主导的 6168 顶点（z 122.6~150.9）是裙腰和上身，本身跟随动画、不走物理，这部分是设计如此；穿模来自更低的裙摆层。
- **形态键默认值**：按作者 VRChat 预设写入 `Breasts_closer=1`（身体/上衣/裙子）、`Toe_highheels=1`（配高跟鞋）、`Back_long` / `Bangs_front_long` / `Left|Right_side_long`（长发款式）。
- **Twist 骨**：模型自带 `Upper_Arm_Twist` / `Lower_Arm_Twist` 两根，通过 `adapt_humanoid.merge_bones` 合并进上臂/前臂后由自动细分的 16 根魂 Twist 骨接管，避免挥刀时手腕拧麻花。
- **眨眼**：保留 `eye_blink` 形态键（UE 名 `Blink`），后处理 ABP 事件图表定时驱动，平均约 4.2 秒一次。
- **材质槽**：5 个槽 —— `Face`（脸）、`FaceAlpha`（眼睛透明层）、`Skin`（皮肤）、`Costume1`（全部服装+头饰+假阴影）、`FrontHair`（全部头发）。灵魂材质都是不透明 PBR，**`Wendy_Face_alpha` 与 `Wendy_Hair_Fakeshadow` 目前按不透明绘制**，眼睛与阴影层可能被盖住/变成色片，详见下方已知限制。
- **金属度**：服装 ARM 贴图由 `Wendy_clothes_metal_mask.png` 生成（遮罩白=金属 1.0、粗糙 0.32），未使用大面积的 body 遮罩，避免白裙被渲染成银甲。

## 已知限制
- **面部与渲染风格**：只驱动眨眼；其余表情、口型未驱动。借用魂的写实 PBR 材质实例（平法线 + 常量 ARM），不含 lilToon 卡通阴影与描边，原画里的粉白渐变与描边会偏白偏硬。
- **眼睛透明层风险**：`Wendy_Face_alpha`（瞳孔/眼白透明叠加）与 `Wendy_Hair_Fakeshadow`（假阴影）都在不透明材质上绘制，游戏里可能出现眼睛被盖住或刘海下一块色片。若确实如此，把 `model.drop_materials` 改成 `["Wendy_Hair_Fakeshadow"]`（或连同 `Wendy_Face_alpha`）后重打。
- **贴图覆盖范围**：覆盖了 `MI_ZeroHun_Cap_01_b` 与 `MI_ZeroHun_Cloth_01_b ~ 04_b` 引用的 18 张贴图；这些材质实例若在游戏别处也被引用，会一起变。
- **物理待实机微调**：`default-phys` 的刚体参数为离线经验值（尾巴×腿、裙摆×腿开了碰撞；袖子与头发未开碰撞），尚未进游戏实测。裙摆这次改成软参数（`stiff` 60 / `swing` 70°），目标是让腿把裙子推开；若实机出现「裙子下摆穿过大腿正面之后从内侧透出」或者“裙摆前后反向掏进去”，把 `skirt.stiff` 再降到 40 并同时降 `damp` 到 24；若出现无风自动乱飘，反向提高 `stiff` 到 120。尾巴若展开过头就降 `tail.swing`，若根本不展开就降 `tail.stiff` 到 30。
