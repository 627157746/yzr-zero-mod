# Ciel 双手握持修正验证记录

验证日期：2026-11-11。游戏数据：Steam build 26367565 / UE 5.7.4。

本次生成了新的 `default-phys` 与 `default-basic`。它们通过本地构建、烹饪、成品引用检查和离线动画求值；**尚未进游戏验证**。没有向游戏目录部署文件。

## 原因与改动

全身比例适配改变了左右手在动画中的相对位置。此前「模型手腕到魂手腕误差 0.0 cm」只能证明模型跟随源姿势，无法证明手在武器上。长兵器常态待机中，左手相对原版武器握点偏约 18 cm。

在 `mods/ciel/mod.json` 配置 `soul.two_hand_grip`，公共管线生成魂身体后处理 `ABP_SoulGrip`。它将右手的变换复制给 `ik_hand_gun`，使用动画的原始 IK 双手相对关系，驱动左臂 IK 恢复握持。超过臂长可达范围时沿刀轴滑动握点，保持手臂长度。

开关依据是左手目标到武器局部 Z 轴的距离；这是几何筛选，不是游戏提供的“双手握持”状态。12 cm 内完全修正，20 cm 外不修正，中间线性混合。臂长可达比例 0.97，沿刀轴滑动与右手的最小间隔 9 cm。

同时修正了生成器的引脚默认值写入：动画蓝图编译器会用未连线引脚的默认值覆盖节点结构体，导致编辑器显示复制开关为 True，烹饪后却为 False。现在同步两处值，并直接检查成品中的 CopyBone/TwoBoneIK 常量。

预览工具在旋转转为欧拉角前归一化 ACL 导出的四元数，避免微小非单位长度被放大成额外姿势偏差。

## 实际执行的验证

- `tools/build-tools.ps1 -SkipExport` 编译编辑器模块成功。
- 两版均执行 `tools/build-mod.ps1 -Mod ciel -Variant default -SkipPrepare`（basic 添加 `-NoPhys`），包括 UE 生成、编译、烹饪、打包和成品检查，全部通过。
- `verify_release.py` 确认覆盖资源来源、魂骨架来自原游戏、身体保留游戏骨架和 PA_Hun、显示部件骨架/动画蓝图/材质正确；握持蓝图来自 mod，未引用 `/Script/PbzModEditor`，复制平移和旋转已实际写入成品，TwoBoneIK 目标和极向量正确。
- 两版均运行 `preview-retarget.ps1 -Mod ciel -Count 8 -NoRender`，13 段动作 × 8 帧模型到魂的左右手腕误差均为 0.0 cm（保留一位小数）。源身体后处理由真实 UE 临时骨骼组件执行，再把结果交给模型重定向器；不以数学公式代替动画蓝图求值。

为避免只测静止姿势多次 tick 收敛后的结果，另对导出的完整动画每帧更新一次：

| LongBlade_Stance_Idle | 151 | 0.0132 cm |

非握持对照：双刀常态、双刀战斗待机、双刀跑步、蛇双刀待机、徒手待机、徒手跑步和软剑战斗待机，每组 24 帧，共 168 帧。GripAlpha 全为 0；除有意更新的 `ik_hand_*` 辅助分支外，骨骼组件空间位置与旋转不变。

最大统计深度两边均为 3.0 cm。这是按现有脚本“躯干面附近、法线反侧”的近似计数，包含衣袖/裙体匹配，累计值可能重复计算不同帧的同一顶点；不等于真实游戏碰撞。总量下降，部分动作局部计数略升，不能宣称穿模全部改善。

已读图确认常态待机左手与目标标记重合，战斗待机的手沿轴滑动；预览不渲染武器网格，仍需游戏里检查实际刀柄、掌心与手指接触。

眨眼回读：Blink 形态键 `lod0 deltas=1281 moved=1271 max_delta_cm=4.206`；事件图中 SetMorphTarget 的名字、执行线和数值线均正确。Blender 重新渲染权重 0 / 0.5 / 1 并读图确认闭合正常。

## 修改文件

- `ProjectPBZ/Source/PbzModEditor/PbzModEditorLibrary.cpp` / `.h`：握持蓝图生成、字段及引脚同步、回读、离线真实组件求值。
- `tools/ue/setup_assets.py`：按配置创建握持蓝图并设置身体后处理引用。
- `tools/ue/preview_retarget.py`：执行源身体后处理，分别统计重定向与武器握持误差，保留修正前姿势，归一化动画旋转。
- `tools/verify_release.py`：成品身体后处理、蓝图来源与节点参数检查。
- `tools/blender/render_retarget.py`：原版握点绿色标记。
- `mods/ciel/mod.json`：启用握持配置并增加相关预览动作。
- 安装说明、参数参考、排错记录与工作区指引：记录实际行为和局限。

## 交付与待验证项

使用 release 下新生成的 `Ciel-two-hand-grip-phys.zip` 或 `Ciel-two-hand-grip-basic.zip`，二选一。压缩包包含 `~mods/` 下三个成品文件和安装说明。请优先复测：双手武器攻击后停止操作回到常态，再检查移动、重新攻击、拔收刀、单手与双刀。

尚未验证：游戏实际身体后处理是否执行且先于替换模型重定向、完整状态混合、所有武器和处决动作、不同帧率/LOD、模型次级物理运行效果，以及掌心/每根手指接触。参数读取上一帧已求值骨骼，权重和滑动存在一帧滞后；纯几何筛选可能在未覆盖的动作中误判。上述限制不能由编译或离线检查替代。
