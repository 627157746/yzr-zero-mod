# Ciel（シエル Ver1.00）替换成年魂 — 安装说明

## 当前状态
- **采用通用独立管线（`tools/extract_package.py` + `tools/blender/adapt_humanoid.py` + `tools/ue/setup_assets.py`）构建，离线验证 9 段动作 72 个采样点手部误差全部为 `0.0 cm`（尚未进游戏实测，状态：未验证）。**
- 源模型：`source/ciel_1.0.unitypackage`（ArmoireLepus / Ciel Ver1.00，VRChat Humanoid 模型，36540 顶点、189 骨）。
- 配置：`mods/ciel/mod.json`（纯声明式配置，无需专属钩子脚本）。

## 版本（只装一个，文件名相同，换版本直接覆盖）
| 文件夹 | 说明 |
|---|---|
| `default-phys`（推荐先试） | 双马尾 / 刘海 / 猫耳 / 猫尾 / 裙摆 / 蝴蝶结飘带含次级物理（`RigidBody`），带双马尾×躯干、裙摆×双腿防穿模碰撞 |
| `default-basic` | 同模型、同贴图，**完全无次级物理**；若物理出现抖动或穿模可用作对照 |

## 适用范围
- Steam 版《影之刃零》，build 26367565。游戏更新后可能失效。
- 只替换成年魂的默认服装；少年魂、其他服装、过场动画未逐一适配。
- 不需要 UE4SS，纯 `.pak/.ucas/.utoc` 静态封包，只改模型与贴图，不改游戏脚本或原版骨架 `Hun_Skin_Skeleton`。

## 安装
1. 退出游戏。
2. 打开游戏目录：Steam 右键《影之刃零》→ 管理 → 浏览本地文件（文件夹名 `PBZ`）。
3. 把版本文件夹里的 `~mods` 整个复制到 `PBZ\ProjectPBZ\Content\Paks\`，覆盖同名文件。装好后应有：
   `PBZ\ProjectPBZ\Content\Paks\~mods\zzz_Ciel_P.pak`、`.ucas`、`.utoc` 三个文件。
4. 若装过其他「替换魂」mod，请先把它们移出 `~mods`（所有替换魂的 mod 只能同时装一个）。
5. 启动游戏，读取成年魂存档。

## 卸载
退出游戏，删除 `PBZ\ProjectPBZ\Content\Paks\~mods\` 下的 `zzz_Ciel_P.pak`、`.ucas`、`.utoc` 三个文件即可。

## 核心技术改进（解决「大宽肩、猩猩臂、端肩架肘」）
1. **全身 `AnimationScaled` 逆向适配（`soul.adapted_pose_json`）**：
   - 魂原版骨架中 `Pelvis`、`spine_01..05`、`clavicle`、`upperarm`、`lowerarm`、`thigh`、`calf`、`foot` 及全部 `twist` 骨骼均为 `AnimationScaled` 模式（仅 `hand_l/r` 为 `Animation` 模式，固定长 `25.40205 cm`）。
   - `tools/blender/adapt_humanoid.py` 将魂空身体网格（`Hun_Body_Simple`）的 42 根全身骨骼平移适配到 Ciel 的关节比例（骨盆缩放 `0.889`、锁骨肩宽缩放 `0.471`、上臂 `0.688`、前臂 `0.904`），并使躯干与锁骨父关节的局部平移方向与魂 `orig_t` 完全平行，彻底消除因成年男性肩高（150.6 cm）高于少女肩高（137.8 cm）导致的端肩与架肘。
2. **前臂袖管轴向适配 + 袖口百褶刚性平移零形变**：
   - 在 T-pose 下将前臂轴段精准对齐魂 `hand_l/r` 的 `25.40205 cm` 局部长度，末端 `2.0 cm` 的束口蓝环与百褶荷叶边袖口做纯刚性平移（0% 拉伸变形），手掌绕腕关节等比放大 `1.12x` 贴合刀柄。
3. **静止姿势烘焙（`Apply Pose as Rest Pose`）+ 16 根四肢 Twist 骨细分**：
   - 在 Blender 中将全身四肢、手腕、五指对齐魂的静止姿势并烘焙为新静止姿势，自动细分 `Spine_02/03`、`UpperChest`、`Neck_02` 与 16 根四肢 Twist 骨，按投影线性插值重分配蒙皮权重，消除挥刀时手腕/肩膀扭曲。
4. **离线重定向验证结果（`preview-retarget.ps1`）**：
   - 待机、慢走、跑步、冲刺、闪避、破军攻击、偃月刀攻击共 **9 段动作 72 个手部采样点误差全部为 `0.0 cm`**。

## 已知限制
- **面部与渲染风格**：有定时眨眼（平均约 4.2 秒一次，间隔随机抖动，单次闭合约 42 ms）；其余表情、口型仍未驱动。借用魂的写实 PBR 材质实例（平法线 + 常量 ARM），不含 VRChat lilToon 卡通阴影与描边。
- **贴图覆盖范围**：覆盖了 `MI_ZeroHun_Cap_01_b` 与 `MI_ZeroHun_Cloth_01_b ~ 05_b` 引用的 18 张贴图。
- **物理待实机微调**：`default-phys` 的刚体物理参数基于离线经验值配置，尚未进游戏实测；如遇剧烈抖动请切换 `default-basic` 并反馈具体动作截图。
